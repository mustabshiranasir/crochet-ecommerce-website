# Love Crochet — E-Commerce Website

A multi-page front-end e-commerce website for handcrafted crochet products, built as a Web Technologies course project at COMSATS University Islamabad, Attock Campus.

## About the Project

Love Crochet is an online store showcasing handmade crochet items including fashion accessories, bouquets, home decor, and hair accessories. The site features a responsive layout, sticky navigation bar, product listings with prices, a blog section, and user account pages.

## Pages

- **Home** — Hero section, featured product categories, shop now button
- **Fashion** — Crochet bags, sweaters, keychains, mittens
- **Bouquet** — Handmade crochet flower bouquets
- **Hair Accessories** — Scrunchies, headbands, hairpins, bandanas
- **Home Decor** — Cushions, coasters, wall hangings, table accessories
- **Blog** — Articles and updates
- **Accounts** — User login and registration interface
- **Search** — Product search page

## Tech Stack

| Technology | Usage |
|---|---|
| HTML5 | Page structure and content |
| CSS3 | Styling, layouts, responsive design |
| JavaScript | Navbar, sticky header, last section interactions |
| Font Awesome | Icons throughout the site |
| Google Fonts | Dancing Script, Lobster, Merriweather, Roboto Slab |

## Features

- Sticky navigation bar that highlights on scroll
- Product cards with images, names, and prices
- Heart/wishlist icon on product images
- Multi-page navigation between categories
- Custom fonts for an elegant handcrafted feel
- Responsive layout for different screen sizes
